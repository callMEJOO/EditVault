EditVault — Withdrawals Standalone V3 | 05 Nov 2026

اللي اتغير:
1) صفحة سحب مستقلة برابط /withdrawals، مش جوه Creator Studio.
2) لينك "السحب" في قائمة الحساب وقائمة الموبايل (لصناع المحتوى والأدمن فقط)، ومع زر سريع على شاشات الديسكتوب الكبيرة.
3) تصميم Dark/Lime منفصل: 3 بطاقات إحصائية، طرق السحب، خارطة مراحل الإطلاق، وآخر 6 مبيعات.
4) أنيميشن دخول متدرج وحركات hover وتصميم متحرك + عدادات نقاط متحركة باستخدام React requestAnimationFrame. Respect prefers-reduced-motion.
5) بيانات الإحصائيات جاية من السيرفر في GET /api/studio/withdrawals/overview مع JWT والتحقق من role.
6) السحب ما زال مقفول فعليًا: POST /api/studio/withdrawals => 403. لا يتم استقبال أرقام محافظ ولا تحويل النقاط لفلوس.
7) بيحافظ على ميزات V2: البحث عن الحسابات والشارات والتوثيق.

خطوات التثبيت على جهازك:
1. اعمل نسخة احتياطية من قاعدة بياناتك لو المشروع على سيرفر حي.
2. فك ZIP داخل المجلد الأساسي edit-marketplace (مش داخل client ولا server).
   المفروض يبقى edit-marketplace\EditVault-Withdrawals-Standalone-V3\INSTALL.bat
3. شغّل INSTALL.bat. السكربت بيعمل backup تلقائي للملفات القديمة داخل _editvault-backups.
4. لو ظهرت مشكلة DATABASE_URL اتأكد إن server\.env موجود وبوستجرس شغالة.
5. أعد تشغيل API وReact؛ ادخل بحساب Creator وافتح /withdrawals أو من قائمة الحساب > سحب الأرباح.
6. جرّب npm run build من client علشان تتأكد من بناء الواجهة.

- مفيش موعد إطلاق للسحب، ومش بنجمع بيانات تحويل حساسة حاليًا.
- لا توجد مكتبات إضافية مطلوبة للأنيميشن؛ React + CSS وlucide-react الموجودة بالمشروع.
