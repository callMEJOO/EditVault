EditVault — TikTok username follower lookup

التغيير:
- لا يوجد TikTok Login ولا يطلب من الـ Creator ربط حسابه أو إدخال كلمة مرور.
- من Profile يكتب المستخدم اسم TikTok فقط (username أو @username) أو رابط الصفحة العامة.
- بعد الضغط على Save profile، يحاول الموقع جلب عدد المتابعين تلقائياً. يوجد زر Fetch / refresh followers لإعادة المحاولة.
- عدد المتابعين يُخزَّن في قاعدة البيانات ويظهر في الصفحة العامة مع تاريخ آخر تحديث.
- لتقليل الاستهلاك، يتم استخدام العدد المخزن لمدة 6 ساعات قبل السماح بطلب جديد.
- مفتاح مزود البيانات محفوظ على السيرفر فقط، وليس في الواجهة أو عند المستخدمين.

مزود lookup المستخدم في هذه النسخة: Apify Actor `automation-lab/tiktok-scraper`, mode `profiles`.
حساب Apify ومفتاح API مطلوبان من صاحب المنصة، وليس من كل Creator:
https://console.apify.com/account#/integrations
التكلفة حسب الاستخدام وليست ثابتة؛ صفحة المزود تعرض حالياً تقديراً يقارب 0.009 دولار لاستعلام ملف شخصي واحد على السعر الأساسي، وقد تتغير الأسعار والرصيد المجاني.

إعداد المفتاح:
1) افتح server/.env (وليس client/.env).
2) أضف السطر التالي، واستبدل القيمة بمفتاحك الحقيقي:
   APIFY_API_TOKEN=ضع_مفتاح_Apify_هنا
3) لا ترسل المفتاح في المحادثة، ولا تضعه في كود React.
4) أوقف API ثم أعد تشغيله.
5) من نافذة client نفّذ `npm run build`، ثم أعد تشغيل `npm run dev`.
6) افتح Profile، اكتب username أو رابط TikTok، ثم Save profile.

اختبار دون API key:
ستُحفظ بيانات الصفحة العادية، لكن lookup سيعرض رسالة تقول إن APIFY_API_TOKEN غير مضبوط. لن يظهر رقم مختلق.

تنبيه مهم حول الامتثال والاستقرار:
هذه ليست واجهة TikTok الرسمية؛ المزود يقرأ بيانات الصفحات العامة آلياً، وقد يتعطل أو تتغير نتائجه أو يتطلب رصيداً مدفوعاً. شروط TikTok تنص على تقييد الاستخراج الآلي للبيانات ما لم يكن مسموحاً به كتابةً. قبل استخدامه تجارياً، راجع شروط TikTok وشروط مزود البيانات وتأكد أن استخدامك مسموح. إذا كان لازم الالتزام بالمسار الرسمي المدعوم من TikTok، فالبديل هو API الرسمي، والذي يتطلب موافقة المستخدم/تفويضه للوصول إلى الإحصاءات.

التثبيت:
- فك الضغط داخل مجلد المشروع الذي يحتوي client وserver.
- افتح PowerShell من جذر المشروع.
- نفذ:
  Set-ExecutionPolicy -Scope Process Bypass
  .\username-tiktok-stats\apply-username-tiktok-stats.ps1
- ثم أضف مفتاح Apify إلى server/.env كما سبق.
- نفّذ npm run build داخل client.

يُنشأ مجلد Backup بجذر المشروع قبل نسخ أي ملفات. لا يحذف السكريبت ملفات الرفع أو بيانات المشتريات.
