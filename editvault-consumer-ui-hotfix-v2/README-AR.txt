EditVault — إصلاح الشاشة السوداء (الإصدار الثاني)

المحاولة السابقة توقفت بأمان ولم تعدّل ملفاتك لأنها لم تتعرف على شكل الكود بدقة. هذا الإصدار يستخدم محددات أوسع ويعمل نسخة احتياطية قبل أي تعديل.

1) أوقف Vite فقط من نافذة الواجهة بـ Ctrl+C، واترك السيرفر الخلفي كما هو.
2) فك ضغط الحزمة في جذر المشروع بحيث يظهر tools/fix-consumer-ui-black-screen-v2.js.
3) افتح CMD في جذر المشروع ونفّذ:
   "C:\Program Files\nodejs\node.exe" tools\fix-consumer-ui-black-screen-v2.js
4) إذا قال إنه نجح، شغّل الواجهة:
   cd client
   npm run dev
5) افتح الموقع واضغط Ctrl+Shift+R.

إذا قال إن تأثير عنوان الصفحة موجود أصلًا في مكان سليم، أو إن نمط الكود غير معروف، لا تحاول تعديلات يدوية أخرى. افتح الموقع، اضغط F12 ثم Console، وانسخ أول رسالة حمراء كاملة.
