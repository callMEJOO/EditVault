تحديث Creator Studio + معاينات الفيديو + صفحة الـ Creator العامة
===============================================================

المميزات المضافة
----------------
1) عند رفع Edit جديد، اختار الفيديو الأصلي، وحدد Start وEnd بالثواني من مشغل الفيديو.
   المعاينة المقبولة من 3 إلى 60 ثانية. السيرفر يقص الجزء المختار فعليًا باستخدام FFmpeg
   ويحفظه كملف MP4 منفصل يظهر للعامة؛ الفيديو الأصلي لا يظهر في الكتالوج العام.
2) من My Edits يمكنك تعديل الاسم والوصف والتصنيف والسعر وبرنامج المونتاج.
3) Change preview يحمّل الأصل لصاحب الإيديت فقط داخل Creator Studio، ويتيح اختيار جزء جديد
   من دون رفع الملف الأصلي مرة ثانية.
4) Remove يشيل الإيديت من التصفح العام بطريقة آمنة، مع الاحتفاظ بسجلات الشراء والملفات
   حتى لا تتعطل تنزيلات العملاء السابقين.
5) صفحة عامة لكل Creator: اسم الصفحة، رابط TikTok، عدد المتابعين، شارة التوثيق على المنصة،
   وكل الإيديتات المنشورة التي لها Preview صالح.
6) روابط أسماء الـ Creators في الكتالوج تفتح صفحة الـ Creator العامة.
7) تغيير المعاينة لا يعتمد على كاش قديم؛ يتم تعطيل التخزين المؤقت لمسار الفيديو العام.

مهم بخصوص عدد متابعين TikTok
-----------------------------
حقل المتابعين في هذا التحديث يدوي (creator-reported)، ويظهر للزوار على أنه رقم أدخله صاحب
الحساب. لا يوجد توصيل تلقائي إلى TikTok API ضمن هذا الباكدج، ولم يتم اختراع رقم أو الادعاء
بأنه متحقق من TikTok. ربط الرقم تلقائيًا يحتاج إعداد تطبيق TikTok وصلاحيات/API مناسبة.

طريقة التركيب
-------------
1) فك الضغط عن مجلد creator-upgrades داخل جذر مشروع edit-marketplace، بجوار client وserver.
2) افتح PowerShell في جذر المشروع، ونفّذ:

   Set-ExecutionPolicy -Scope Process Bypass
   .\creator-upgrades\apply-creator-upgrades.ps1

3) السكريبت ينشئ Backup بالملفات المتغيرة، يركب ملفات الواجهة والـ API، يحاول تثبيت ffmpeg-static،
   ويحاول تطبيق تحديثات قاعدة البيانات.
4) لو ظهرت رسالة أن قاعدة البيانات لم تتحدث، افتح PowerShell داخل server ونفّذ بعد التأكد من
   إعداد server/.env واتصال قاعدة البيانات:

   node src/db/apply-creator-features.js

5) لو ffmpeg-static لم يثبت تلقائيًا:

   cd server
   npm install ffmpeg-static

6) أعد تشغيل API ثم Vite. وبعدها نفّذ اختبار البناء:

   cd client
   npm run build

ملاحظات التشغيل
---------------
- يظل شرط توثيق حساب الـ Creator الموجود بالمشروع قائمًا لرفع إيديت جديد.
- تعديل بيانات الإيديت أو إزالته من المتجر يتطلب تسجيل الدخول وملكية الإيديت (أو صلاحية Admin).
- قص المعاينة على السيرفر يحتاج ffmpeg-static مثبتًا.
- حجم الفيديو الأقصى يخضع لإعداد MAX_UPLOAD_MB الموجود بالسيرفر.
- يوجد Backup في مجلد يبدأ اسمه بـ backup-creator-upgrades-.
