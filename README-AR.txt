EditVault Scene Pack Community V1 — نسخة تجريبية
===============================================

الإضافة:
• تبويبان داخل صفحة Scene Packs: "تصفّح الحزم" و"ارفع سين باك".
• أي مستخدم مسجّل يمكنه رفع حزمة ZIP / 7Z / RAR مع غلاف، أو إرسال رابط تحميل.
• الحزم الجديدة من الأعضاء تدخل قائمة "قيد المراجعة" ولا تظهر في السوق قبل موافقة الأدمن.
• عند موافقة الأدمن على حزمة أصلية مرفوعة كملف، صاحبها يحصل على 5 نقاط.
• الحد: مكافآت 3 حزم فقط خلال آخر 7 أيام (15 نقطة كحد أقصى لهذه المكافأة).
• حد الرفع: حزمتان خلال آخر 24 ساعة، وحتى 3 حزم بانتظار المراجعة.
• رفع رابط خارجي أو تكرار نفس ملف الأرشيف لا يعطي مكافأة.
• المكافأة تُحتسب مرة واحدة فقط للحزمة، والتكرار في طلب القبول لا يكرر النقاط.
• عرض حالة الحزم الشخصية والحدود في نفس صفحة الرفع. واجهة عربية/إنجليزية/إسبانية.
• الحزم المنشورة سابقًا تُحافظ على وضعها الحالي، ولا يتم صرف نقاط بأثر رجعي.

خطوات التثبيت على ويندوز:
1) اقفل الـBackend والـFrontend مؤقتًا (Ctrl+C).
2) فك ضغط الملف في جذر مشروعك:
   C:\Users\ys757\Music\edit-marketplace-mvp\edit-marketplace
3) افتح CMD (ليس PowerShell) وشغّل:
   cd /d "C:\Users\ys757\Music\edit-marketplace-mvp\edit-marketplace"
   node tools\apply-editvault-scene-pack-community-v1.cjs
4) لا تنفذ الخطوة التالية قبل ظهور SUCCESS. نفّذ تحديث قاعدة البيانات:
   cd server
   node src\db\apply-scene-pack-community-v1.js
5) لو ظهر SUCCESS، شغّل Backend هنا: npm run dev
6) افتح CMD ثانية، شغّل الواجهة:
   cd /d "C:\Users\ys757\Music\edit-marketplace-mvp\edit-marketplace\client"
   set "VITE_API_URL=http://localhost:5000"
   npm run dev
7) افتح http://localhost:5173/scene-packs وجرب بحساب تجريبي ثم وافق من حساب أدمن.

لو سكريبت التركيب رفض بسبب اختلاف ملفات مشروعك:
• لا تستبدل ملفات client/server كاملة من نسخة قديمة.
• ابعت ZIP جديد من مشروعك الحالي، وسنجهز نسخة متوافقة. لا تكرر السكريبت بعنف.
• التحديث يُجري نسخًا احتياطية تحت backups/before-scene-pack-community-...

ملاحظات مهمة قبل النشر للعامة:
• لا ترفع فيديوهات محمية بحقوق لا تملك إذن توزيعها.
• التحقق من SHA-256 يمنع التطابق الحرفي للملفات وليس التحايل على المحتوى.
• هذا التحديث لا يوفر مضاد فيروسات ولا فحص محتوى تلقائي؛ فحص الملفات والإبلاغ وحذف المخالفات ومراجعة حقوق النشر ضرورية قبل فتح الموقع لعامة الجمهور.
• حد 500MB هو الحد الأقصى السابق؛ راقب مساحة التخزين واستهلاك الشبكة، وقلّله بمتغير البيئة MAX_SCENE_PACK_MB إذا احتجت.
• لا يوجد اختبار تلقائي مع قاعدة بيانات المستخدم الفعلية؛ جرّب سيناريوهات الرفع والقبول والسحب بحسابات تجريبية قبل إطلاقه.
