EditVault — تنظيم صلاحيات المبدعين وصورة البروفايل
====================================================

ما الموجود في هذه الحزمة؟
- واجهة مختلفة للمستخدم العادي وللحساب الذي فعّله الأدمن كمبدع.
- زر Creator Studio يظهر فقط للأدمن أو للمبدع الذي حالته verified.
- لوحة للأدمن لمراجعة طلبات المبدعين وقبولها أو رفضها.
- شارة المبدع الموثّق تظهر بعد الموافقة الإدارية.
- صورة بروفايل قابلة للرفع/التحديث/الإزالة؛ تظهر في شريط الحساب وصفحة المبدع العامة.
- انتقالات خفيفة ودعم prefers-reduced-motion.
- مسار API جديد للصورة ومهاجرة قاعدة بيانات تضيف avatar_data_url.

قبل التركيب
------------
1. خذ نسخة احتياطية من مجلد المشروع وخصوصًا client/src وserver/src/index.js.
2. فك ضغط الحزمة في جذر المشروع:
   C:\Users\ys757\Music\edit-marketplace-mvp\edit-marketplace
   وافق على استبدال ملفات client/src عند الطلب. الحزمة تحتوي المسارات النسبية client/src وserver/src.
3. لا تستبدل server/src/index.js من الحزمة؛ لا يحتوي على index.js كامل عمدًا، حفاظًا على ربط Apify ومسارات مشروعك الحالية.

توصيل مسار صورة البروفايل في السيرفر
-------------------------------------
افتح server/src/index.js وأضف سطر require بجانب بقية ملفات routes:

const profileMediaRoutes = require('./routes/profile-media');

ثم أضف mount بجانب بقية app.use الخاصة بالـ API، قبل معالج الأخطاء النهائي:

app.use('/api/profile', profileMediaRoutes);

تأكد أن السطرين مضافان مرة واحدة فقط.

ترحيل قاعدة البيانات
---------------------
افتح PowerShell:

cd "C:\Users\ys757\Music\edit-marketplace-mvp\edit-marketplace\server"
node src/db/apply-profile-photo.js

المفروض تظهر:
Profile photo migration applied.

تشغيل واختبار
-------------
شغّل السيرفر:

npm run dev

وشغّل واجهة client في نافذة منفصلة:
cd "C:\Users\ys757\Music\edit-marketplace-mvp\edit-marketplace\client"
npm run dev

اختبر بهذه الخطوات:
1. سجّل الدخول كمستخدم عادي: يستطيع التصفح والشراء، ولا يظهر له Creator Studio.
2. افتح Profile وارفع صورة، واحفظها؛ تأكد من ظهورها في الشريط العلوي.
3. احفظ رابط TikTok لإرسال طلب المراجعة. حسب منطق السيرفر الموجود، تغيير رابط TikTok قد يضع الحالة في pending.
4. سجّل الدخول بحساب الأدمن وافتح زر Admin في الشريط العلوي؛ سيصل إلى Creator applications.
5. اضغط Approve creator أو Reject. القبول يستعمل المسار الموجود:
   POST /api/creators/verification/:userId/review
6. بعد الموافقة، سجّل الدخول بالحساب الذي تمت الموافقة عليه أو حدّث الصفحة. يجب أن تظهر شارة Verified creator ويظهر زر Creator Studio.
7. افتح صفحة المبدع العامة للتأكد من ظهور الصورة والشارة.

مهم بخصوص الصلاحيات
---------------------
الواجهة لا تمنح المستخدم دور creator من المتصفح. التفعيل يعتمد على مسار مراجعة الأدمن في server/src/routes/creators.js، الذي يجب أن يظل محميًا بواسطة adminOnly. لا تغيّر هذا المسار إلى قبول تلقائي. يجب أن تبقى حماية السيرفر المرجع النهائي حتى لو حاول مستخدم استدعاء API يدويًا.

صورة البروفايل
---------------
تُصغّر الصورة في المتصفح إلى JPEG قبل الإرسال. تُخزّن في حقل PostgreSQL جديد اسمه avatar_data_url. هذا مناسب لصورة شخصية صغيرة لكل حساب، وليس لتخزين صور أو فيديوهات كبيرة.

------------
