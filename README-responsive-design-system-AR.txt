EditVault — نظام تصميم موحّد ومتجاوب لكل الشاشات

الهدف
- توحيد الإحساس البصري والمسافات وسلوك الكروت والنماذج بين صفحات الموقع.
- منع التمدد الأفقي وتداخل العناصر بقدر ما تسمح به البنية الحالية.
- تحسين تخطيط الصفحات عند أحجام الكمبيوتر والتابلت والموبايل، مع دعم الشاشات الضيقة جدًا.
- جعل النوافذ المنبثقة قابلة للتمرير داخل الشاشة بدل خروجها خارج حدود الجهاز.
- تحسين التركيز بلوحة المفاتيح واحترام إعداد تقليل الحركة.

طريقة التثبيت
1. فك ضغط الملف داخل مجلد المشروع:
   C:\Users\ys757\Music\edit-marketplace-mvp\edit-marketplace
2. افتح CMD في جذر المشروع نفسه، وتأكد أن المسار يحتوي على client وserver وtools.
3. نفّذ:
   "C:\Program Files\nodejs\node.exe" ".\tools\apply-editvault-responsive-design-system.js"
4. لو ظهرت رسالة نجاح، افتح الموقع واضغط Ctrl + Shift + R.
5. لو كان Vite متوقفًا، شغّله بالطريقة المعتادة من مجلد client.

احتياطات
- السكربت يعدّل client/src/main.jsx لإضافة استيراد CSS واحد، وينشئ client/src/responsive-design-system.css.
- يُنشئ نسخة احتياطية من main.jsx، ومن ملف CSS الجديد إن كان موجودًا قبل التثبيت.
- لا يعدّل ملفات السيرفر أو قاعدة البيانات أو الصلاحيات أو بيانات المستخدمين.
- التغيير طبقة CSS إضافية فوق التنسيقات الحالية؛ لا يحذف تصميم الصفحات الأصلي.
- بعد التثبيت، اختبر الصفحات المهمة على عرض 320 و390 و768 و1024 و1440 بكسل. إذا ظهر تداخل في صفحة بعينها، أرسل لقطة شاشة للصفحة عند المقاس الذي ظهرت فيه المشكلة، وسنعمل إصلاحًا محددًا لها.
